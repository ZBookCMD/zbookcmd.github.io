Minimal System v0.2-Alpha

On August 21, 2024, version v0.2-Alpha was released based on FemboyOS.
The release was released as QEMU and UTM virtual machines on x86_64 architecture.
It has all the same features and utilities as FemboyOS Pre-release 3. Just added kernel and a couple of additional utilities.
